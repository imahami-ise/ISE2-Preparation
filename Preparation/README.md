# 📈 Objectif

Valider mon année ISE 2 avec une forte moyenne en développant :

- une bonne maîtrise des bases mathématiques et statistiques ;
- une compréhension solide des méthodes ;
- une bonne maîtrise des logiciels statistiques ;
- une capacité à résoudre les exercices de manière autonome ;
- une organisation régulière du travail.
